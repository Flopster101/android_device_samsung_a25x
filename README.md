## Recovery Device Tree for devices based on the Exynos 1280 SoC

### Supported devices:
* Galaxy A25 5G (a25x)
* Galaxy A33 5G (a33x)
* Galaxy A53 5G (a53x)
* Galaxy M33 5G (m33x)
* Galaxy M34 5G (m34x)

## How-to compile it:

```sh
. build/envsetup.sh
lunch twrp_uni1280-eng
make recoveryimage
```
